# Support Page Draft (for App Store Connect - Support URL)

## Contact us
If you need help or have questions about privacy, reach us at:

- Email: support@example.com

## Privacy requests
To submit a privacy request (for example, access or deletion), include the account email you used to sign in (or your user identifier) and a description of your request.

## Reporting issues
If you encounter a bug or issue, include:
- Device model and iOS version
- Approximate time of the issue
- Any error message you saw
